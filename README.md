This is a full deobfuscator for the lua obfuscator by zko inside webism. 
this deobfuscator is made by axom. 

# INSTALLATION 

`` git clone https://github.com/axomtools/zkowebism-deobf-by-axom ``
`` cd zkowebism-deobf-by-axom ``

# USAGE

this runs on the input and shows the output inside the terminal without saving :
`` python run.py inputfilename ``

this runs input and saves output as file :
`` python run.py inputfilename > outoutfilename ``
